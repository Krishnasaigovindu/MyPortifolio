# Krishna Sai Govindu - React Portfolio

This is a modern, responsive personal portfolio website built with **React**, **Vite**, and **Framer Motion**.

## 🚀 Quick Start

1. **Install Dependencies**:

    ```bash
    npm install
    ```

2. **Run Development Server**:

    ```bash
    npm run dev
    ```

3. **Build for Production**:

    ```bash
    npm run build
    ```

## 📂 Project Structure

- `src/components/`: Reusable UI components.
- `src/App.jsx`: Main entry point.
- `src/index.css`: Global styles.
