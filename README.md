# Krishna Sai Govindu - Portfolio Website

This is a responsive, modern personal portfolio website built with HTML5, CSS3, and JavaScript.

## 🚀 How to Run

Simply open the `index.html` file in any modern web browser.

1. Navigate to the project folder: `c:\Users\krish\Downloads\MyPortifolio`
2. Double-click `index.html`.

## 📂 Project Structure

- `index.html`: The main structure of the website.
- `style.css`: Contains all styling, variables, and animations.
- `script.js`: Handles the mobile navigation toggle and scroll animations.
- `images/`: Directory for project images (Backgrounds, Project Screenshots).

## 🎨 Customization

- **Colors**: Edit the `:root` variables in `style.css` to change the color scheme.
- **Content**: Update `index.html` with new projects or skills as you grow.
- **Images**: Place your own images in the `images` folder and reference them in `index.html`.

## 📱 Responsiveness

The site is fully responsive and optimized for:

- Desktop
- Tablets
- Mobile Devices
